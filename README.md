# สีเขียวพิริยาลัย · Triple Crown — Champion & Time Capsule Edition

ผังแสตนเชียร์ 15 × 10 (คอลัมน์ A–O, แถว 10 → 1) ของคณะสีเขียว พิริยาลัย
16 เพลง · 151 เฟรม · 21 สี — ฉบับอนุสรณ์หลังคว้าแชมป์ครบ 3 รายการ
(สแตนเชียร์ · เชียร์หลีดเดอร์ · ขบวนพาเหรด) ในผึ้งน้อยเกมส์ ครั้งที่ 50

เว็บนี้เปิดให้แคป/พิมพ์/แชร์ได้อย่างเสรี ประกอบด้วยมุมมองแสตน ใบเพลง แกลเลอรี
วิเคราะห์ ผังชื่อเล่น 150 คน ระบบค้นหาชื่อ/ที่นั่ง/ชั้น และ **ป้ายประจำตัวฉบับแชมป์**
ที่ดาวน์โหลดการ์ด IG Story เป็น PNG และพิมพ์ป้ายชื่อ A4 แนวนอนเป็น PDF ได้
(ป้ายชื่อมีชื่อเล่น ชื่อจริง ชั้น เลขที่ และที่นั่ง — ช่องข้อมูลส่วนตัวอื่นแสดง “ไม่ระบุ”)

จุดสำคัญ: **ข้อมูลไม่ได้ฝังในโค้ด** ทุกอย่างแก้ได้จากตาราง CSV ใน `tools/data/`
และแต่ละเฟรมมีระยะเวลาเป็นบีตของเพลงจริง

> ข้อมูลนักเรียนใน `tools/data/students.json` เก็บเฉพาะฟิลด์ที่ปลอดภัย
> (ชื่อเล่น ชื่อจริง ชั้น เลขที่ ที่นั่ง) — **ไม่มีเบอร์โทรหรือข้อมูลสุขภาพ**
> และ build จะปฏิเสธไฟล์ที่มีคีย์ต้องห้าม · ป้ายชื่อที่พิมพ์ออกมาจึงแสดงช่อง
> เบอร์โทร/แพ้ยา/แพ้อาหาร/โรคประจำตัว เป็น “ไม่ระบุ”

## แก้ข้อมูลหลังบ้าน

ทุกอย่างอยู่ใน `tools/data/` — เปิดด้วย Excel / Google Sheets / Notepad
แล้วบันทึกเป็น **CSV UTF-8** (Excel: “CSV UTF-8 (Comma delimited)”)

```bash
python3 tools/build_data.py --check   # ตรวจอย่างเดียว
python3 tools/build_data.py           # สร้างข้อมูล + bump ?v=
docker compose restart web            # index.html เป็น bind mount ไฟล์เดี่ยว
```

build จะบอก `ไฟล์:บรรทัด` เป็นภาษาไทยถ้าข้อมูลผิด และจะไม่เขียนทับจนกว่าจะแก้ครบ
รายละเอียดคอลัมน์ทั้งหมดอยู่ที่ [`tools/data/README.md`](tools/data/README.md)

## ไทม์ไลน์ตามบีตจริง

ระยะเวลาแต่ละเฟรม:

```text
frame_ms = beats × 60000 / bpm
```

- `bpm` และ `default_beats` อยู่ที่ระดับเพลงใน `songs.csv`
- `beats` รายเฟรม override ได้ใน `frames.csv`
- ค่าเริ่มต้น 180 BPM / 16 บีต = 5.3 วินาทีต่อเฟรม (ถ้าเฟรมไหนไม่ระบุ `beats`)
  — ไทม์ไลน์จริงของทั้งงาน (151 เฟรม) ตอนนี้ 6:58
- เพลงที่จับเวลาจากการแสดงจริงแล้วใช้ BPM ของตัวเอง 12 เพลงตามลำดับแสดง:
  13 = 200, 1 = 223, 2 = 148, 3 = 149, 14 = 160, 4 = 169, 5 = 171, 6 = 160,
  7 = 158, 8 = 157, 11 = 157, 12 = 155 (เหลือ 15, 9, 16, 10 ที่ยัง 180 รอข้อมูลจริง)
- **เพลง 5–12 ตั้งใจเล่นช้ากว่าเสียงแสดงจริง ~1.5 เท่า** (ผู้ใช้ขอให้เฟรมช้าลงเพื่อร้องตามทัน)
  — เพิ่ม `beats` รายเฟรมแต่คง `bpm` เดิม เมโทรนอมจึงเคาะความเร็วเท่าเดิม
  ท่อนที่เฟรมถี่มากได้เวลาเพิ่มมากกว่าท่อนค้างภาพ (เฟรมสั้นสุด ~0.76 วิ)
  เฟรมยังเริ่มที่บีตเต็มและผลรวมบีต % 4 == 0 ตามปกติ
- ทุกเฟรมเริ่มที่บีตจำนวนเต็ม → **ภาพเปลี่ยนตรงจังหวะที่ 1 ของห้อง** และภาพกับ
  เมโทรนอมขับเคลื่อนจากนาฬิกาบีตตัวเดียวกัน (`showBeatStart`) จึงไม่หลุดกัน
- ใส่ `beats` เป็นจำนวนคี่ก็ได้ แต่ถ้าอยากให้เปลี่ยนลงห้องให้ใช้ทวีคูณของ 4
- ช่อง **BPM** ในแถบเล่น / โหมดโรงหนัง / แผงตั้งค่า ใช้ปรับจังหวะเฉพาะเพลงนั้น
  — ค่าเริ่มต้นดึงจาก `songs.csv` และปรับได้ 40–240 โดยไม่แก้ไฟล์ต้นฉบับ
- ตอนเล่นอัตโนมัติมีเสียงเมโทรนอมเคาะ **ทุกบีต (4/4 เน้นบีต 1)**
  ที่นับต่อเนื่องข้ามเฟรม (ค่าเริ่มต้นเปิดอยู่
  กดปุ่มลำโพงหรือ `M` เพื่อเปิด/ปิด — ระบบจำค่าที่เลือกไว้)
- บนมือถือมีปุ่มคำพูด (mini HUD และโหมดโรงหนัง) สำหรับเปิด/ปิด **เนื้อเพลงลอยบนแสตน**
  — เปิดแล้วคำร้องจะลอยเหนือแสตนเหมือนซับในยูทูป ปิดแล้วเห็นแค่หน้าแสตน
  (ค่าเริ่มต้นปิด · จำค่าที่เลือกไว้ · ในโหมดโรงหนังคำร้องจะยังอยู่แม้คอนโทรลจางหาย)
- เพลงที่ยังไม่มีผังโค้ด (รหัส 1, 5, 13, 16) ใส่เป็น **เฟรมขาวชั่วคราว** 8 บีต/เฟรม
  ในลำดับโปรแกรมจริง รอผังโค้ดฉบับจริง
- ตอนเล่นอัตโนมัติ ไทม์ไลน์เดินตามเวลาและหยุดที่เฟรมสุดท้าย
- ลากไทม์ไลน์จะ snap เข้าเฟรมที่ตรงกับเวลาจริง

หา BPM ของเพลง: เปิด `tools/tap-tempo.html` แล้วแตะตามจังหวะ
หรือใช้สูตรใน [`tools/data/README.md`](tools/data/README.md)

หลัง build ดูเวลาของทุกเฟรมได้ที่ `tools/out/timing-report.csv`

## เปิดดูในเครื่อง

เปิด `index.html` ได้โดยตรง หรือรัน static server:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

> ฟอนต์ Prompt / JetBrains Mono โหลดจาก Google Fonts
> ถ้าไม่มีอินเทอร์เน็ตจะ fallback เป็นฟอนต์ระบบตามที่กำหนดใน CSS

## Deploy (เครื่องนี้)

```bash
docker compose up -d
docker compose restart web   # หลัง build ทุกครั้งที่ index.html เปลี่ยน
```

เว็บเสิร์ฟที่ `http://100.100.225.94:8080/` และผ่าน Cloudflare Tunnel
`http://stand-green.singto1597.xyz/`

`?v=YYYYMMDD-N` ใน `index.html` ถูก bump อัตโนมัติโดย `build_data.py`
เพื่อกัน Cloudflare/browser cache ค้าง — ไม่ต้องแก้เอง
